# 🎓 Student Grade Calculator in C

## 📌 Project Description

This is my first C programming project.

The Student Grade Calculator is a simple program that takes a student's name and marks in five subjects, calculates the total marks and percentage, and displays the final grade.

## 🛠️ Features

- Accepts student name.
- Takes marks in five subjects.
- Calculates total marks.
- Calculates percentage.
- Displays the student's grade.
- Uses conditional statements to determine grades.

## 💻 Concepts Used

- `printf()` and `scanf()`
- Variables and data types
- Arithmetic operators
- `if-else` statements
- Basic input and output

## ▶️ How to Run

Compile the program:

```bash
gcc grade_calculator.c -o grade_calculator
```

Run on Windows:

```bash
grade_calculator.exe
```

Run on Linux/macOS:

```bash
./grade_calculator
```

## 📊 Grading System

| Percentage | Grade |
|---|---|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 40–59 | D |
| Below 40 | F |
